# Third-party notices

## Memory Forest

Memory Garden is a port, to RemNote, of the concept, growth model and rendering approach of
**Memory Forest**, an Anki add-on by **Barak Levy**.

- Original project: <https://github.com/baraklevy20/memory-forest>
- Licence: MIT

Memory Garden's core data layer (growth-stage thresholds, the health model, the pond and
milestone rules) reimplements Memory Forest's ideas in TypeScript for the RemNote plugin SDK —
no source file copied verbatim, but the derived work is substantial.

**The rendering engine is different: `src/vendor/memory-forest/web/` is Memory Forest's own
`web/` directory, copied in unmodified** (`reference/memory-forest/web/`, the public/base
edition — checked for and confirmed free of any Plus-only or differently-licensed content; see
`DECISIONS.md` § "Region packs" for that check). File headers are untouched; `LICENSE` is
copied alongside it. Memory Garden's own code adapts our RemNote data into the payload shape
this engine expects (`src/forest/mfAdapter.ts`) and adds new environments/visitors through the
engine's own registries rather than editing vendored files — any edit that genuinely can't be
avoided is marked `// Memory Garden change:` inline and listed in `DECISIONS.md`.

### On assets

Memory Forest's `LICENSE` is a single MIT licence covering the whole repository, with no separate
licence file in any asset folder. Its image assets (`docs/**.png`, `docs/**.gif`,
`settings/scenery/*.png`, `settings/nature/*.png`, `settings/patreon_*.png`) are screenshots,
recordings and UI previews of the add-on, plus Patreon branding.

**Memory Garden copies none of the image assets** (screenshots, recordings, UI previews, Patreon
branding) — only the rendering *code* under `web/`, per the vendoring note above. Every pixel on
screen is still generated by code (either the vendored engine's or Memory Garden's own region/
creature data feeding it), never a copied image file. See `DECISIONS.md` § "Region packs".
