**Memory Forest**, an Anki add-on by **Barak Levy**.

- Original project: <https://github.com/baraklevy20/memory-forest>

source file is copied verbatim, but the derived work is substantial — the growth-stage thresholds,
the health model, the pond and milestone rules, the tone-map tree renderer and the ASCII sprite
format all follow the original closely. The MIT licence of the original is reproduced in full

### On assets

Memory Forest's `LICENSE` is a single MIT licence covering the whole repository, with no separate
licence file in any asset folder. Its image assets (`docs/**.png`, `docs/**.gif`,
`settings/scenery/*.png`, `settings/nature/*.png`, `settings/patreon_*.png`) are screenshots,
recordings and UI previews of the add-on, plus Patreon branding.

**Memory Grove copies none of them.** Every pixel Memory Grove draws is generated by its own code:
plants from `src/forest/plants.ts`, creatures from ASCII sprite data in `src/regions/*/creatures.ts`,
terrain and sky from `src/forest/*.ts`. Where the two projects overlap visually it is because they
share a technique and a palette philosophy, not an asset. See `DECISIONS.md` § "Art and assets".
